## 目标与预期行为

开发独立 Cordis 插件，通过 DeepSeek Harness 公开接口加载、列入插件列表，并支持系统设置插件列表启停。向目标 Agent 注册符合 Agent Tools 标准的 `text_to_speech` 工具，将文本转换为音频，支持调用参数指定音色。

密钥由用户通过环境变量配置，仅在服务端读取。缺少配置不影响宿主启动且不发起请求。禁用或卸载撤销注册、取消本地请求并释放资源。单次调用不自动重试，避免重复计费。

## 决策与待确定项

已确定：文本转语音、支持音色参数、服务端环境配置、公开接口加载与注册、禁用撤销工具、失败不自动重复提交。

拟定：包名 `dsh-plugin-text-to-speech`，工具名 `text_to_speech`；必填 `text`，可选 `voice`，指定音色覆盖服务端默认值。无指定音色且无默认值时返回明确错误，不修改原始朗读文本。

实现前确定：

1. 模型和默认音色、兼容范围、文本限制及官方错误结构；已测试的示例值不等于所有账号或音色均可用。
2. 首版采用非流式返回音频 URL 的方案，以及宿主结果展示方式；URL 有效期与到期字段按官方契约呈现。
3. 北京业务空间域名与宿主环境加载入口，不将密钥或服务地址开放给 Agent 覆盖。
4. 总超时、工具取消信号、目标 Agent 工具可见性及系统设置 UI 扩展路径。

关键产品或架构歧义解决后再实现；不能确定的需求记录为待确认或阻塞，不凭空补接口或宣称完成。
