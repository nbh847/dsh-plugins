# Image Generation 插件规范

## 定位与边界

本项目用于开发 DeepSeek Harness 的 Cordis 图片生成插件，模型为 SenseNova U1.5 Lite。当前处于实现阶段：官方唯一公开契约为同步图像接口，经用户 2026-10-02 决策，原「创建任务后每 5 秒轮询」需求废弃，实现改为工具内同步长请求，不做伪装的任务轮询。

插件与 dsh 分开存放，作为独立插件维护，由父目录 `dsh-plugins` 仓库统一管理，不建立嵌套 Git 仓库。实现代码、构建配置、测试及配套客户端代码均保存在本项目，不搬入 dsh 源码树。dsh 通过外部插件引用加载，仅依赖公开接口，不依赖宿主内部源码。提交及推送按用户明确指令执行。

## 目录与职责

- `README.md`：当前状态、配置文件说明与文档入口。
- `ROADMAP.md`：实施顺序、待确认事项与验证记录。
- `docs/design.md`：需求、宿主集成、两阶段生成流程与验收标准。
- `.env.example`：无密钥的环境变量模板；`.env`：用户本地配置，不纳入版本控制。
- `src/` 与 `tests/`：按 `docs/design.md` 计划结构实现；不创建无对应设计的空源码或伪造可运行入口。
- `.tmp/<task-slug>/`：任务临时文件，不作为运行依赖。

## 工作流与验证

进入项目先读取本文件及 `ROADMAP.md`；开始实现前核对 `docs/design.md` 的待确认项，以及宿主当前公开接口。宿主源码只读参考路径为 `/Users/mac/workspace/opensource/deepseek-harness`，不得将此路径硬编码为运行依赖。

工具注册使用宿主公开接口，插件禁用或卸载时释放注册与进行中的请求资源。API Key 只在宿主服务端读取，不进入 Agent 工具参数、浏览器配置、日志或工具结果。

官方端点、鉴权、模型标识和响应字段经核对后才能写入实现（核对记录见 `docs/design.md` API 核对状态）；实现为同步接口，不添加无契约依据的任务轮询。必要验证入口见设计文档，未实现能力不得描述为已可用。
