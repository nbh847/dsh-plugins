## 交付范围

- `video_lint`：原生静态合约检查，保留 findings。
- `video_snapshot`：1--9 个时间点，固定 3 列，保留顺序和重复项，返回图片附件。
- `video_render`：原生 MP4 渲染，返回文件附件与宿主交付卡片。
- 整体启停、工作区权限、受管子进程、取消及卸载清理。
- 宿主设置页集成补丁与真实测试产物。

## 使用前置条件

宿主源码已应用设置页补丁，安装包不会自动修改其他宿主。原有 Web 服务未重启，本机 `PATH` 未找到 FFmpeg／FFprobe；按 README 指定已有二进制路径后重启使用实例。未提交、推送或发布。
