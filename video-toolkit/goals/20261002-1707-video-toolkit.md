## 目标与预期行为

在本项目开发独立 Cordis 插件 `dsh-plugin-video-toolkit`，包装 HyperFrames 原生 lint、snapshot 和 render 能力，注册到 DeepSeek Harness 插件列表，并在系统设置插件列表支持持久化启用和关闭。启用时向 Agent 注册三个标准工具，禁用或卸载后撤销注册并终止本插件正在执行的任务。

| 工具 | 参数 | 预期结果 |
| --- | --- | --- |
| `video_lint` | 必填绝对目录路径 `project_path` | HyperFrames 静态合约检查结果，区分检查发现问题与命令执行失败 |
| `video_snapshot` | 必填 `project_path`、`timestamps` 秒数数组，1--9 项 | 指定时间点截图与固定 3 列拼图，按输入顺序排列；9 张为 3×3，末行不足留空 |
| `video_render` | 必填 `project_path` | 本地有效 MP4 文件及可核实的产物信息 |

三个工具的目标目录必须是可识别的 HyperFrames 项目。截图用于视觉检查，不自动宣称画面质量通过；静态 lint 不替代运行时检查。截图结果须可供 Agent 查看，MP4 须可供用户访问，不能仅以服务端文件存在作为完整交付。

3. 项目入口识别、时长读取及 `0`、末帧、超出时长的精确处理。
4. 宿主工作区路径权限、工具权限声明、图片输出与视频访问接口；不能假设服务端路径天然可供客户端访问。

6. 各工具超时、进程树取消、浏览器及服务器资源释放方式，实际集成 profile 与环境前置条件。

关键产品或架构差异未解决前不进入依赖它的实现；独立核对和文档工作可继续。
